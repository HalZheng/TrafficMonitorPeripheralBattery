# Settings

The plugin creates `PeripheralBatteryPlugin.ini` in the TrafficMonitor plugin
configuration directory on first load.

Two ways to edit it:

- **Options dialog** — the plugin manager's “选项” button opens a Win32 dialog
  with the refresh interval, max devices, display mode, the device list and
  per-device enable/name/label/priority/colour. OK writes the INI back.
- **Direct editing** — the INI stays a plain text file and can be edited by hand
  or generated by a script. Comments and unknown keys are kept on normal
  restarts; the file is only regenerated when it is missing or a new device
  section is needed.

Changes require a TrafficMonitor restart, because the host caches plugin item
pointers.

## TrafficMonitor host settings

The plugin implements `ITMPlugin::OnExtenedInfo` and follows these host
settings, so it does not need its own duplicate toggles:

| Extended info | Host option | Effect in this plugin |
|---|---|---|
| `EI_TASKBAR_WND_NOT_SHOW_PERCENT` | 任务栏窗口“不显示百分号” | Removes `%` from the taskbar value and shrinks the item width. |
| `EI_MAIN_WND_NOT_SHOW_PERCENT` | 主窗口“不显示百分号” | Same, for the main-window item. |
| `EI_DRAW_TASKBAR_WND` | 任务栏窗口显示/隐藏 | Stops updating the taskbar item and drops host text colours when the taskbar window is off. |
| `EI_LABEL_TEXT_COLOR` | 标签文字颜色 | Used for the label when the host provides a colour. |
| `EI_VALUE_TEXT_COLOR` | 数值文字颜色 | Used for the percentage text when the host provides a colour. |

The plugin's own `color` field only controls the battery fill; it does not
override the host's text colours. There is no plugin-side “hide percent”
switch — the host setting is the single source of truth.

## Schema

```ini
[plugin]
refresh_interval_seconds=30
max_devices=4
priority_mode=fixed
show_offline=true
display_mode=bar

[device:g03_pro]
enabled=true
name=AUSDOM G03 Pro
label=G03
priority=10
color=#4FC3F7

[device:flydigi_direwolf_4]
enabled=true
name=Flydigi Direwolf 4
label=Direwolf
priority=30
color=#FFB74D
```

## Fields

| Field | Values | Meaning |
|---|---|---|
| `refresh_interval_seconds` | 5–3600 | Polling interval. |
| `max_devices` | 1–8 | Maximum number of taskbar items. |
| `priority_mode` | `fixed` | `fixed` sorts by per-device `priority`. `lowest` and `charging` are reserved. |
| `show_offline` | `true`/`false` | Show `--` when a device is offline; `false` shows an empty value. |
| `display_mode` | `bar` / `text` | `bar` draws the battery outline and fill; `text` uses the old host-rendered `G03 84%` style. |
| `device:<id>.enabled` | `true`/`false` | Include this device in the active list. |
| `device:<id>.name` | string | Name shown in TrafficMonitor's display settings. |
| `device:<id>.label` | string | Short taskbar label. |
| `device:<id>.priority` | integer | Lower values sort first in `fixed` mode. |
| `device:<id>.color` | `#RRGGBB` | Fill colour in `bar` mode. Low battery (≤20%) overrides with red; charging overrides with green. |

## Item IDs

`device:<id>` must match the `DeviceDescriptor::id` in
`src/core/DeviceRegistry.cpp`. The same ID is used in TrafficMonitor's
`plugin_display_item` list.

## Adding settings for a new device

The plugin automatically creates default sections for every descriptor in the
registry. Users only need to override the fields they care about.
